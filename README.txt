ChenLib — система управления каталогом книг, разработанная на Django. 
Поддерживает добавление, просмотр, фильтрацию и удаление книг, имеет удобный интерфейс для управления информацией.

Python 3.13.13
Django 6.0.6
Pillow 12.2.0

Основные возможности
Главная страница: Отображение общей статистики (количество книг, категорий, авторов и бестселлеров)
Управление книгами: Добавление, просмотр и удаление книг с полной проверкой введённых данных
Фильтрация по категориям: Отбор книг по выбранной категории
Страница детальной информации: Просмотр полных данных о книге (обложка, автор, цена, описание и т.д.)
Административная панель: Управление всеми данными через стандартную панель Django Admin

Основные модели данных
- Book: Основная информация о книге (название, ISBN, цена, количество страниц, дата публикации и др.)
- Category: Разделы для группировки книг
- Author: Данные об авторе (пол, гражданство, биография)
- Tag: Тематические метки для книг

Инструкция по запуску
- Выполните миграцию базы данных:python manage.py migrate
- Создайте суперпользователя для входа в админ-панель:python manage.py createsuperuser
- Запустите сервер разработки:python manage.py runserver

Адреса для доступа
Главная страница:http://127.0.0.1:8000/
Список книг:http://127.0.0.1:8000/books/
Добавить книгу:http://127.0.0.1:8000/books/add/
Административная панель:http://127.0.0.1:8000/admin/ (требуется вход под суперпользователем)
